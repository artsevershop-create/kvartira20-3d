# Квартира 20 · 6 этаж · 3D

Одна страница `index.html` (three.js r128 из `vendor/`, без сборки). Локально: `node D:/cache/claude-scratch/parter3d/serve.js D:/dev/kvartira20-3d 8093` → http://localhost:8093.
Опубликовано: https://artsevershop-create.github.io/kvartira20-3d/

Основа — «Планировочное решение 1 вариант» (`D:\dev\Kvartira 20\планировка №148_1 вариант.pdf`). Размеры сняты из векторного PDF
(масштаб 0,063 pt/мм, проверен по цепочке 4570): внутренний контур 13,0 × 6,0 м, стена к лестничному холлу 250 мм, три наружные 500 мм,
перегородки 110–140 мм, окна 1830 (слева) и 1540 (справа). Площадь 72,8 м² — из штампа квартиры 20 на плане 6 этажа (`6 эт (1).pdf`).
Размеры проектные, до контрольного обмера.

Как в демо УДСД: стены срезаны на 1,1 м в виде сверху; «3D прогулка» идёт по маршруту через двери (сетка 10 см + A*, сквозь стены не пройти),
схема квартиры с размерами в панели слева (на телефоне — мини-карта справа внизу), комнаты в схеме кликабельны, в прогулке показана позиция;
три отделки (Светлая / Графит / Тёплая), «План этажа» — соседи 17, 18, 19 и лестнично-лифтовой узел схематично, «Вечер».

## Альбом дизайн-проекта

`album/Дизайн-проект-кв20.pdf` — 54 листа А3 в формате рабочего альбома (как у студийных дизайн-проектов): обложка, содержание, пояснительная записка,
19 ракурсов-визуализаций с ключ-планом и штампом, варианты отделки, планы (обмер, демонтаж, монтаж, строительный, мебель, пол, плинтус, потолок и свет,
выключатели, розетки, тёплый пол, кондиционирование, двери, сантехника), развёртки стен всех помещений, ведомость отделки, чертежи встроенной мебели.
Всё построено из той же 3D-модели: `index.html` пишет каждую коробку мебели в `window.__kv.data.boxes`, генератор в `album/tools/` (`shots.js` — рендеры
в headless Chromium, `build.js` — HTML-листы с SVG-чертежами, `topdf.js` — PDF). Пути в скриптах — локальные (D:\cache\…). Визуализации — схематичные,
по 3D-модели, не фотореалистичные; размеры — проектные, до контрольного обмера; инженерные планы — предложение, не рабочая документация.
